# Estado del programa

`LEARNING_STATE.md` resume el progreso vigente y `EVIDENCE_LOG.md` conserva observaciones reales en un historial append-only. Los archivos iniciales no contienen dominio evaluado.

`LAST_HANDOFF.md` **no viene precreado**: se genera tras la primera sesión real mediante `/close`, usando `sets-framework/core/SESSION_HANDOFF.md` y `sets-framework/templates/LAST_HANDOFF.template.md`.

`CONCEPT_MAP.md` es opcional. Puede registrar relaciones conceptuales útiles dentro de este programa, pero no sustituye evidencias ni es un cuarto artefacto obligatorio de `/close`.

Flujo: `/close` → revisar archivos propuestos → guardar en Git → actualizar fuentes del Proyecto de ChatGPT → abrir otro chat del mismo Proyecto y usar `/resume`. No hay sincronización automática.

El programa comienza limpio por decisión del estudiante. No importar progreso de otras especializaciones ni reemplazar evidencia real sin respaldo.
