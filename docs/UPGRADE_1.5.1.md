# Actualización — sets-backend-architecture 1.5.0 → 1.5.1

## Propósito

Alinear este programa con SETS Framework v1.4.1 y hacer explícitas tres libertades de aprendizaje —tecnología, currículo y casos— sin perder el foco de Backend Architecture & Design.

## Cambios

- Las tecnologías familiares siguen disponibles como puentes opcionales, pero no son whitelist, stack predeterminado ni cuota de uso.
- El currículo `B00–B14` es un mapa de prioridades, no un límite exhaustivo. Los temas pertinentes fuera del índice se pueden enseñar en contexto.
- El casebook ofrece casos iniciales; el caso conductor no es obligatorio y pueden utilizarse casos nuevos o aportados por el estudiante.
- Fundamento, profundización y especialización son niveles adaptativos, no fases obligatorias ni prerrequisitos universales.
- Se explicita el límite de dominio para mantener el foco de Backend Architecture & Design y evitar la deriva.
- Se añaden cinco checks manuales; no se consideran aprobados hasta ejecutarlos y registrar evidencia.
