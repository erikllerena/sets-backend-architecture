# ADRs — Backend Architecture

Documentar decisiones reales del ámbito de este programa con plantilla `sets-framework/templates/ADR_TEMPLATE.md`. Las decisiones compartidas entre capas deben ser propiedad del programa integral; enlazar en lugar de duplicar.


Esta guía trata ADRs **técnicos** sobre soluciones y diseños; no es `DECISION_ENGINE.md` (razonamiento pedagógico), ni una guía de decisiones administrativas del programa. Se incorpora como fuente solo cuando el trabajo con ADRs lo justifique.
